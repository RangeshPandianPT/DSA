# 📅 Daily Challenges

Store your daily problem-solving submissions from LeetCode Daily Challenges, HackerRank, and GeeksforGeeks in this directory.

## Naming Convention
Follow the date-prefixed file naming format:
```
YYYY-MM-DD_ProblemName.java

Example:
2026-02-17_DailyChallengeTemplate.java
```

## Daily Workflow
1. Read the problem statement carefully and identify constraints.
2. Duplicate `2026-02-17_DailyChallengeTemplate.java` and rename it for today's challenge.
3. Write the solution, analyze Time/Space complexity in docstrings, and run verification tests using `TestRunner` or `main`.
4. Update `PROGRESS.md` with your completion status!
