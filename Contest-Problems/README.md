# 🏆 Contest Problems

Save interesting, challenging, or instructive problems encountered during timed competitive programming contests (LeetCode Weekly/Biweekly Contests, Codeforces, CodeChef, HackerRank) in this directory for review and post-contest upsolving.

## Naming Convention
```
ContestName_ProblemName.java

Example:
LeetCodeWeekly385_MostFrequentPrime.java
CodeforcesRound920_Square.java
```

## Best Practices for Contest Review
- **Upsolve:** If you couldn't solve a problem during the live contest, revisit it within 24 hours after reading editorials or top submissions.
- **Document Gotchas:** Note edge cases (e.g., integer overflow, $O(n^2)$ TLE constraints) in the file docstring.
